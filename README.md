# Drobe

**Your digital wardrobe.** Digitize what you own and get AI-picked daily outfits. Live at [drobe-blush.vercel.app](https://drobe-blush.vercel.app).

This repository is the Drobe landing site, built with Next.js and TypeScript and deployed on Vercel.

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
